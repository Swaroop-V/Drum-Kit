🥁 Drum Kit

A simple, interactive drum kit web application that allows users to play drum sounds by clicking on buttons or pressing keys on the keyboard. This project showcases DOM manipulation, event handling, and basic audio integration using JavaScript.

---

🔧 Tech Stack

- **HTML5**  
- **CSS3**  
- **JavaScript (Vanilla JS)**  

---

🎯 Features

- Click-based and keyboard-based sound triggers  
- Responsive layout for desktop and mobile  
- Visual button animations on interaction  
- Lightweight and fast-loading
